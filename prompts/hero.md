# Нүүрний hero зураг солих заавар

Hero-гийн гэрэл зургийг (desktop / утас) шинээр generate хийж солих бүрт энэ
дарааллаар яв. Prompt-ууд: [hero-desktop.md](./hero-desktop.md), [hero-mobile.md](./hero-mobile.md).
Код: `src/features/marketing/home-content.ts` (`HERO_PHOTO`),
`src/features/marketing/components/home/campaign-hero.tsx` (`PhotoHero`).

## 0. Текст, зураг хаана, яаж гарах

Админ UI **байхгүй** — hero-гийн текст ба зураг хоёулаа кодод, солих нь
PR → `main` → deploy (Vercel). Feature flag хэрэггүй (feature биш, агуулга).

- Текст: `home-content.ts` → `HOME_CAMPAIGNS`-ийн мөр (`eyebrow`, `title`,
  `description`, утсанд богино `mobileDescription`, `primary`/`secondary` холбоос).
- **Хуваарь:** `startsOn` / `endsOn` (Улаанбаатарын огноо, хоёулаа хамааруулна).
  Шинэ кампанит ажлыг урьдчилан нэмж deploy хийвэл тэр өдөр өөрөө солигдоно,
  дуусахаар `EVERGREEN_HERO` руу буцна. Хуучин мөрийг дууссаны дараа устга.
  Нүүр хуудас `revalidate = 60` тул шилжилт шөнө дундаас ~1 минутын дотор гарна.
- Шинэ кампанит ажил өөр зурагтай бол `HERO_PHOTO`-той ижил хэлбэрийн шинэ const
  нэмээд `image:`-д өг; evergreen-ийн зургийг тусад нь үлдээ.
- Текстийн урт: desktop гарчиг ~2 мөрт багтах (`w-[52%]`), утсан дээр 380px-ээс
  нарийнд зөвхөн гарчиг + товч гарна. Монгол текстийг үсгийн алдаагаар шалга.

## 1. Зохиомжийн дүрэм — яагаад ийм харьцаа вэ

Карт нь `object-cover`, өндөр нь дэлгэцээр хязгаарлагдана (`sm:max-h-[58svh]`,
`min-h-64/80/88`), тиймээс зураг үргэлж бага зэрэг тайрагдана. Зургийг тайралтыг
даахаар зохионо — кодыг зураг руу тааруулж засахгүй.

| | Desktop (≥640px) | Утас (<640px) |
|---|---|---|
| Файлын харьцаа | **2.8:1** (`sm:aspect-14/5`) | **4:3** (`aspect-4/3`) |
| Картын бодит харьцаа | ≈2.2 … 3.45:1 | 4:3 (тогтмол) |
| Тайралт | дээр/доор ≤~10%, хажуу ≤~11% | бараг үгүй |
| Текстийн бүс | зүүн **0–55%** хоосон хана | зүүн **0–58%** хоосон хана |
| Бараа | хэвтээ **55–88%**, босоо **12–88%** | баруун 58–95% |
| `object-position` | `sm:object-[65%_50%]` | `object-right` |

- Бараа ирмэгт ойртох тусам аль нэг дэлгэц дээр тасарна. Хамгийн их
  тайрдаг нь 1366×768, 1440×900 laptop (намхан өргөн) ба 768px tablet.
- Хүрээний ирмэг хүртэл зөвхөн хана, тавцан, сүүдэр үргэлжилнэ.

## 2. Generate хийх

**Тайрахаар бус, эцсийн харьцаагаар шууд** generate хий. 3:2 дээр барааг жижиг
зураад тайрвал бараа цөөн пикселтэй болж бүдгэрдэг (v1-ийн сургамж).

- Model: `gpt-image-2` (playground: *Size → Custom*), **edits** endpoint, quality **high**,
  `input_fidelity=high`, output **PNG**, 2–4 хувилбар гаргаж сонго.
- Хэмжээ: 16-ын үржвэр, харьцаа ≤3:1, урт тал <3840.
  - Desktop: **3584×1280** (артефакт гарвал 2688×960)
  - Утас: **2048×1536** (эсвэл 1536×1152)
  - 2K / 4K preset (16:9) бүү сонго — дахиад тайрах болно.
- Reference зураг:
  1. **Барааны цэвэр бүтээгдэхүүний зураг** (шошгоны бичиг тод) — эхэнд нь тавь.
     Өмнөх hero-г ганцааранг нь өгвөл түүний бүдэг AI бичгийг дахин хуулна.
  2. Өмнөх hero (`public/desktop.webp`) — зохиомж, гэрэл, өнгө.
- Prompt дахь хувь = эцсийн хүрээний хувь. Бараа, сав солигдвол prompt-ын
  барааны жагсаалтыг л солино; бүсийн хувиудыг бүү өөрчил.
- Жижиг шошгоны бичиг AI-д алдаатай гарч болно («Dsscription» г.м.) — hero-гийн
  хэмжээнд анзаарагдахгүй бол зүгээр, том бичиг (брэнд нэр) зөв байх ёстой.

## 3. Шалгах (кодод оруулахаас өмнө)

- Хэмжээ яг 2.8:1 / 4:3 эсэх.
- Зүүн текстийн бүсэд юу ч байхгүй (утсан дээр зүүн доод буланд товч сууна).
- Бараа: хамгийн өндөр таг дээд ирмэгээс ≥12%, хамгийн доод цэг ≤88%,
  баруун захаас ≥9–12%.
- Шошго 100% томруулахад тод эсэх.

## 4. Файл бэлтгэх

**Файлын нэрэнд үргэлж шинэ хувилбар (`-v4`, `-v5`…) өг.** Ижил URL-д Next-ийн
зургийн кэш, Vercel CDN, Safari хуучин зургийг өгсөөр байдаг.

Эх зургийг `public/desktop.webp` / `public/mobile.png`-д хадгал (дараагийн
generate-ийн reference, хувилбаруудын эх). Дараа нь:

```bash
# Desktop: 1600/2400/3200 өргөн. Next optimizer-ыг АШИГЛАХГҮЙ — `deviceSizes`
# 1600-аар хязгаарлагдсан тул retina өргөн дэлгэцэд 2× сунгаж бүдгэрүүлдэг.
node -e '
const sharp = require("sharp"); const v = process.argv[1];
(async () => { for (const w of [1600, 2400, 3200]) {
  const i = await sharp("public/desktop.webp").resize(w).webp({ quality: 80 })
    .toFile(`public/hero-desktop-${v}-${w}.webp`);
  console.log(w, i.height, Math.round(i.size / 1024) + "KB");
} })()' v4

# Утас: нэг файл, Next optimizer дамжина (утсанд 1320px хангалттай).
node -e '
require("sharp")("public/mobile.png").resize(1600).webp({ quality: 85 })
  .toFile(`public/hero-mobile-${process.argv[1]}.webp`).then(i => console.log(i.width, i.height))' v4
```

Хэрэв эх нь эцсийн харьцаагаар биш гарсан бол `resize`-ийн өмнө
`.extract({ left, top, width, height })`-ээр тайр.

## 5. Код шинэчлэх — `home-content.ts` `HERO_PHOTO`

```ts
src: "/hero-desktop-v4-1600.webp",
width: 1600,
height: <1600 өргөний бодит өндөр>,
srcSet: [1600, 2400, 3200].map((w) => `/hero-desktop-v4-${w}.webp ${w}w`).join(", "),
mobile: { src: "/hero-mobile-v4.webp", width: <өргөн>, height: <өндөр> },
```

- Харьцаа өөрчлөгдсөн бол (2.8:1 / 4:3-аас өөр) `campaign-hero.tsx` ба
  `src/components/shared/skeletons.tsx`-ийн `aspect-*`-ийг хамт соль — гэхдээ
  харьцааг солихоос зайлсхий, §1-ийн тооцоо бүхэлдээ өөрчлөгдөнө.
- `alt`-ийг шинэ бараагаар шинэчил.
- Текстийн өнгө фото дээр бэхлэгдсэн (`text-neutral-950/700`) — цайвар хана
  гэж тооцсон. Бараан дэвсгэртэй зураг хийвэл `HeroCopy`-ийн `tone="photo"`-г засах шаардлагатай.

## 6. Дэлгэц дээр шалгах

`pnpm dev` → нүүр хуудас, дараах хэмжээнүүд (DevTools эсвэл Playwright):

| Viewport | Юуг харах |
|---|---|
| 390×844 (утас) | 4:3 карт, текст зүүн талд, товч зүүн доод буланд |
| 768×1024 | хажуугаас тайралт хамгийн их — бараа баруун захад тасраагүй |
| 1366×768, 1440×900 | дээр/доороос тайралт хамгийн их — таг, флакон бүтэн |
| 1920×1080, DPR 2 | `currentSrc` = `-3200.webp`, шошго тод |

## 7. Цэвэрлэх

- Хуучин хувилбарын файлуудыг (`hero-desktop-v3-*`, хуучин mobile) кодод
  дурдагдахгүй болсныг `grep`-ээр шалгаад устга.
- `hero-desktop.md` / `hero-mobile.md`-ийн prompt-ыг огноо, хувилбартай нь шинэчил.

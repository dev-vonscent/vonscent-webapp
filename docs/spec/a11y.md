# Хүртээмжийн (a11y) шалгалт — 2026-09-13

Backlog §2.6-гийн «Хүртээмжийн шалгалт» ажлын үр дүн. Хамрах хүрээ нь тэнд
бичигдсэнчлэн: **сэрэмжлүүлэх цонхны зөв үүрэг, гарын шилжилт, carousel-ийн
зарлал**. Дээрээс нь шалгалтын явцад олдсон, яг тэр гурван сэдвийн дэргэд
байсан алдаануудыг зассан.

Хэмжүүр нь WCAG 2.2 AA. Монголд хуулийн шаардлага байхгүй тул энэ нь
release-ийн саад биш — гэхдээ доорх алдаанууд нь «сайхан байх» зүйл биш,
гарнаас ажилладаг хүнд сайтыг **ашиглах боломжгүй** болгодог төрлийнх байв.

---

## 1. Зассан зүйлс

### 1.1 Фокус харагдахгүй байсан (WCAG 2.4.7) 🔴

`components/ui/dialog.tsx`-ийн «Хаах» товч дээр `focus:outline-none` байв.

`globals.css` нь `:focus-visible` дээр 2px тойм зурдаг (`@layer base`). Гэвч
Tailwind-ийн `.focus\:outline-none:focus` нь **utility давхаргад** байрлах
бөгөөд специфик нь ч өндөр — хоёр талаасаа base давхаргыг дардаг. Үр дүнд нь
ямар ч dialog дээр Tab дарж «Хаах» дээр очиход фокус **хаана ч харагдахгүй**.

Үүнийг wrapper-ээр ч, глобал CSS-ээр ч засах боломжгүй (тийм ч учраас
`CLAUDE.md`-ийн «`ui/`-г шууд засахгүй» дүрмээс зөвхөн энэ нэг класс хасагдав).
Мөн адил `promo-popup`-ийн зарын холбоос дээрх `focus-visible:outline-none`
хасагдсан.

**Дүрэм болов:** `focus:outline-none` гэж хаана ч бичихгүй.

### 1.2 Сэрэмжлүүлэх цонхны үүрэг (WAI-ARIA APG)

`ConfirmDialog` ба `useConfirm()` хоёр нь `role="dialog"` байв. «Устгах уу?»
гэдэг нь хариу шаардсан тасалдал тул `role="alertdialog"` — дэлгэц уншигч
нээгдэх мөчид агуулгыг нь шууд уншина. Эдгээр нь сайтын БҮХ баталгаажуулалт
(бараа устгах, захиалга цуцлах, багц устгах…) -ыг үйлчилдэг тул нэг засварт
бүгд зассан.

### 1.3 Carousel — буруу семантик ба дуугүй шилжилт

`promo-popup` дээр:

| Байсан | Болсон |
|---|---|
| цэгүүд `role="tablist"` / `role="tab"` | `tabpanel` байхгүй тул tab загвар буруу. Ердийн товч + `aria-current` |
| зөвхөн `aria-label="1-р зар"` | контейнер нь `aria-roledescription="carousel"`, слайд бүр `aria-roledescription="slide"` ба `"N / M"` нэртэй |
| слайд солигдохыг юу ч зарлахгүй | `aria-live="polite"` муж (DOM-д **урьдчилан** байрлуулсан — агуулгатайгаа хамт нэмэгдвэл уншигдахгүй) |
| харагдахгүй слайдууд Tab-д ордог | идэвхгүй слайд `aria-hidden`, холбоос нь `tabIndex={-1}` |
| 5 сек автомат шилжилтийг зогсоох нэрлэсэн арга байхгүй (WCAG 2.2.2) | Зогсоох/Үргэлжлүүлэх товч (`prefers-reduced-motion` үед autoplay огт байхгүй тул товч ч гарахгүй) |
| цэг нь 6px өндөр зорилт | дарах талбай 24px (WCAG 2.5.8 Target Size) |

`product-gallery` дээр мөн: `aria-roledescription`, `aria-live` зарлал,
идэвхгүй слайдыг Tab-аас хасах, жижиг зураг дээр `aria-current`. Автомат
шилжилт нь цэг/жижиг зураг дээр дарахад бүрмөсөн зогсдог байсан дээр
`stopOnMouseEnter` + `stopOnFocusIn` нэмэгдэв — зураг уншиж байхад нь
солигдохгүй. (Тусдаа «зогсоох» товч нэмээгүй: дэлгүүрийн харагдацад
нөлөөлнө, зогсоох арга нь аль хэдийн хоёр байгаа.)

### 1.4 Гарын шилжилт — толгойг алгасах холбоос (WCAG 2.4.1)

`SkipLink` (`components/shared/skip-link.tsx`) нэмэгдэв: дэлгүүр, данс, админ
гурван layout-ийн **хамгийн эхэнд**. Ердийн үед харагдахгүй, Tab дарахад
гарч ирнэ. Өмнө нь админы оператор хуудас бүр дээр хажуугийн цэсний 25
холбоосыг Tab-аар давж байж агуулгад хүрдэг байв.

`<main id="main">` гурван layout-д бүгдэд нь тавигдав (өмнө нь зөвхөн
дэлгүүрийнх байсан).

### 1.5 Өнгө дангаараа мэдээлэл дамжуулж байсан (WCAG 1.4.1)

- Админы sidebar: идэвхтэй хуудсыг зөвхөн дэвсгэрийн өнгөөр хэлдэг байв →
  `aria-current="page"`.
- Тоолуурын badge («3») нь тоо ганцаараа уншигддаг байв → `sr-only`
  тайлбар («3 шинэ захиалга»).
- Галерейн жижиг зураг: идэвхтэйг зөвхөн ring-ээр → `aria-current`.
- Хоёр `<nav>` landmark (мобайл sheet + ширээний багана) нэргүй байсан →
  `aria-label="Админ цэс"`.

### 1.6 Шинэ компонентууд

`EmptyState`, `PageHeader`, `CountBadge` (design.md §6.0) нь дүрсээ
`aria-hidden`-ээр нуудаг (гарчиг нь аль хэдийн текстээр байгаа), тоолуур нь
`sr-only` тайлбартай. Хуулбарлаж бичих бүрд эдгээр алдагддаг байсан.

## 2. Шалгасан, асуудалгүй байсан

- **Форм** — `Field` / `FieldError` нь `htmlFor`, `aria-describedby`,
  `aria-invalid`, `role="alert"`-ийг өөрөө холбодог. Формууд `noValidate`
  бөгөөд алдаа нь монголоор (2.2-ийн засвар).
- **График** — `report-charts.tsx` дээрх бүх график нь `sr-only` бодит
  хүснэгттэй (WCAG 1.1.1). Шинэ огнооны мужийн график ч мөн.
- **Dialog / Sheet** — Radix: Escape, focus trap, scroll lock, буцах фокус
  бүгд бэлэн. `ResponsiveDialog` нь гарчиг, тайлбарыг албадан шаарддаг.
- **Toast** — sonner нь өөрөө `aria-live` муж зурдаг.
- **Дүрс-товч** — бүх дүрсэн товч `aria-label` эсвэл `sr-only` текстэй
  (скриптээр шалгав, үлдэгдэлгүй).
- **Brand marquee** — `prefers-reduced-motion` дээр хөлддөг, давхардсан
  хуулбарууд нь `aria-hidden` + `tabIndex={-1}`.
- **Фокусын арга** — `data-focus` script нь хулганаар дарахад тойм гаргахгүй,
  Tab/сум дарахад гаргана.

## 3. Хийгээгүй, зориудаар

- **Бүрэн гар ажиллагааны тест (axe / Playwright a11y).** Нэмэх нь зөв ч
  release-ийн хамрах хүрээнээс гадуур — CI-д шинэ хамаарал ордог.
- **Өнгөний тодосголын бүрэн аудит.** Theme token-ууд нь `globals.css`-д
  тайлбартайгаа (`6.12:1 on card` г.м.) бичигдсэн; санамсаргүй шалгалтад
  зөрчил илрээгүй.
- **Галерейд тусдаа «зогсоох» товч.** §1.3-ыг үз.

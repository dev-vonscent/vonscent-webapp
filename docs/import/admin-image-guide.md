# Бүтээгдэхүүний зураг оруулах заавар

Админ панелиас зураг оруулахад дагах зүйлс. Техникийн тал нь
`src/lib/storage/prepare-upload.ts` (browser) ба `src/lib/storage/process-image.ts`
(сервер) дээр хэрэгжсэн — энэ бол хэрэглэгчийн талын хураангуй.

## 1. iPhone-ийн формат — эхлээд заавал тохируулна

iPhone-ийн камер анхдагчаар **HEIC** форматаар зураг авдаг. Үүнийг Safari-аас
өөр browser тайлж чаддаггүй, сервер ч мөн адил — тиймээс зураг оруулах үед
татгалзана.

Нэг удаа дараах тохиргоог хийвэл асуудал бүрмөсөн арилна:

> **Тохиргоо → Камер → Формат → «Хамгийн нийцтэй»**
> (Settings → Camera → Formats → Most Compatible)

Үүний дараа камер JPEG-ээр авдаг болно. Хуучин авсан HEIC зургуудыг Photos-оос
экспортлохдоо «JPEG» сонголтоор гаргана.

## 2. Босоо (portrait) байдлаар авна уу

Дэлгэц дээрх бүтээгдэхүүний хүрээ нь **4:5 босоо** харьцаатай
(`product-card.tsx`, `product-gallery.tsx`).

| Хэрхэн авсан | Хүрээнд багтахад |
|---|---|
| **Босоо** (3:4) | ~6% л тайрагдана — тохиромжтой |
| Хэвтээ (4:3) | **40% тайрагдана** — савны хажуу тал таслагдана |

Тиймээс утсаа **босоо байрлалд** барьж авна уу.

## 3. Хэмжээ, формат

- Дэмждэг: **JPG, PNG, WebP, AVIF**
- Эх файл 30MB хүртэл байж болно — browser нь өөрөө 1600px болгож багасгаад
  илгээдэг тул том зураг сонгох нь асуудалгүй
- Сервер дээр бүх зураг **WebP** болж хөрвөнө; 8MB зураг ~550KB болдог
- Нэг бүтээгдэхүүнд дээд тал нь **12 зураг**

## 4. Зөвлөмж

- Цайвар, нэг өнгийн дэвсгэр дээр авбал сав тод харагдана
- Савыг кадрын төвд, дээр доороо жаахан зайтай байрлуул — 4:5 хүрээнд
  тайрагдахад аюулгүй
- Эхний зураг нь каталогийн жагсаалтад харагдана, тиймээс хамгийн сайныг эхэнд
  тавь (админ дээр чирж дараалал солино)

# Бүтээгдэхүүн (үнэртэн) импортлох заавар

Клиентээс үнэртэй усны мэдээллийг цуглуулж DB рүү оруулахад зориулсан загвар.
Бөглөх файл: [`product-import-template.csv`](./product-import-template.csv)

## Яаж цуглуулах вэ

1. `product-import-template.csv`-г **Google Sheets** эсвэл **Excel**-ээр нээнэ.
2. Эхний мөр (толгой) болон 2 жишээ мөрийг **хэвээр үлдээж**, доор нь үнэртэн
   тус бүрээр **нэг мөр** болгон бөглөнө. (Бүх бөглөж дуусаад жишээ 2 мөрийг устгана.)
3. Дуусаад **File → Download → CSV (UTF-8)** хэлбэрээр экспортлоно.
4. Хөгжүүлэгч рүү CSV файлыг өгнө → импорт скрипт ажиллуулж DB рүү оруулна
   (доорх «Импорт» хэсгийг үз).

> **Хамгийн чухал:** 5/10/20ml багц бүрийн **зарах үнийг клиент өөрөө бичнэ**
> (`price_5ml`, `price_10ml`, `price_20ml`). Систем үнэ бодохгүй.
> `bottle_price` / `bottle_ml` нь зарах үнэд нөлөөлөхгүй — үлдэгдэл болон
> борлуулалт/ашгийн тайланд ашиглагдана.

## Багана тус бүрийн тайлбар

| Багана | Заавал? | Зөвшөөрөгдөх утга / формат | Жишээ |
|---|---|---|---|
| `brand` | ✅ | Брэндийн нэр (текст) | `Dior` |
| `name` | ✅ | Үнэртний нэр (текст) | `Sauvage` |
| `gender` | ✅ | `male` / `female` / `unisex` | `male` |
| `concentration` | ✅ | `EDP` / `EDT` / `Parfum` / `EDC` | `EDP` |
| `scent_family` | ✅ | `floral` / `woody` / `fresh` / `oriental` / `citrus` / `spicy` | `fresh` |
| `season` | ➖ | `spring` / `summer` / `autumn` / `winter` / `all` (хоосон бол `all`) | `all` |
| `origin_country` | ✅ | Гарал улс (текст) | `Франц` |
| `release_year` | ✅ | Гарсан он (тоо) | `2018` |
| `bottle_price` | ✅ | **Бүтэн лонхны өртөг ₮** — тайлан/ашгийн тооцоонд | `480000` |
| `bottle_ml` | ✅ | Бүтэн лонхны эзэлхүүн ml | `100` |
| `notes_top` | ✅ | Дээд нот — олныг `;`-ээр тусгаарла | `Бергамот; Чинжүү` |
| `notes_heart` | ✅ | Зүрхэн нот — `;`-ээр тусгаарла | `Лаванда; Сарнай` |
| `notes_base` | ✅ | Суурь нот — `;`-ээр тусгаарла | `Амбра; Кедр` |
| `description` | ✅ | Тайлбар. Доторх таслалын улмаас **хашилтанд (`"…"`) бич** | `"Тунгалаг, шинэхэн үнэр."` |
| `tags` | ➖ | `new` / `hot` / `sale` — олныг `;`-ээр | `hot; new` |
| `on_hand_ml` | ✅ | Одоо байгаа нөөц (нийт ml) | `60` |
| `image_urls` | ✅ | Зургийн URL — олныг `;`-ээр (эхнийх нь нүүр зураг) | `https://…/1.jpg; https://…/2.jpg` |
| `price_5ml` | ✅ | 5ml багцын зарах үнэ ₮ | `38400` |
| `price_10ml` | ✅ | 10ml багцын зарах үнэ ₮ | `64900` |
| `price_20ml` | ✅ | 20ml багцын зарах үнэ ₮ | `110400` |
| `rating_avg` | ➖ | Дундаж үнэлгээ 0–5 (хоосон бол 0) | `4.7` |
| `rating_count` | ➖ | Үнэлгээний тоо (хоосон бол 0) | `128` |

✅ = заавал бөглөнө · ➖ = заавал биш (хоосон орхиж болно)

### Анхаарах
- **Тоон талбарт** таслал, ₮ тэмдэг, зай бүү тавь: `480000` (зөв), `480,000₮` (буруу).
- **Олон утгатай** талбарт (нот, tags, зураг) `;` (цэг таслал) ашиглана.
- **Slug** (URL хаяг) автоматаар үүснэ — `brand` + `name`-ээс (`dior-sauvage`).
  Хэрэв тусгай хаяг хэрэгтэй бол хэлээрэй, баганыг нэмж болно.
- **Зураг:** URL байхгүй бол зургийн файлуудыг (нэрэнд нь brand-name бичсэн)
  өгвөл бид Supabase Storage-д байршуулаад холбоно.
- Ижил `slug`-тай мөр дахин импортлоход хуучин дээр нь **шинэчилнэ** (upsert),
  давхардуулж үүсгэхгүй.

## Импорт (хөгжүүлэгчид)

CSV бэлэн болсны дараа импорт скрипт нь дараах байдлаар оруулна
(одоо байгаа `scripts/seed.ts`-тэй ижил урсгал):

1. `products` — мөр бүрийг `slug`-аар upsert.
2. `product_variants` — 5/10/20ml мөр бүрд `price_*ml` баганы дүнг шууд бичнэ.
3. `product_images` — `image_urls`-г дарааллаар нь оруулна.
4. `inventory` — `on_hand_ml`.
5. `product_tags` — `tags`-г таг-ийн id-тай холбоно.

> Энэ CSV-г уншиж DB рүү оруулдаг импорт скриптийг (`scripts/import-products.ts`,
> ж: `pnpm db:import docs/import/product-import-template.csv`) бэлдэж өгөх боломжтой.

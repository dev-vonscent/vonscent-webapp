# Багц (Base collection) импортлох заавар

Бэлэн багцын (base collection) мэдээллийг Excel-ээр цуглуулж, шууд DB рүү
оруулахад зориулсан загвар ба скрипт.

Бөглөх файл: [`collection-import-template.xlsx`](./collection-import-template.xlsx)

## Яаж бөглөх вэ

1. `collection-import-template.xlsx`-г **Excel** эсвэл **Google Sheets**-ээр нээнэ.
2. **«Багц»** хуудсанд base collection бүрийг **нэг мөр** болгож бөглөнө.
   - `*` тэмдэгтэй багана **заавал**: `Нэр`, `Үнэртэн slug 1–4`.
   - Багц бүр **яг 4 үнэртэнтэй**, 4 slug **давхардахгүй**.
3. Дуусаад **2 жишээ мөрийг устгаад** `.xlsx` хэвээр хадгална.
4. Хөгжүүлэгч рүү файлыг өгнө → доорх скрипт шууд DB рүү уншина.

> **Үнэртний slug** нь `products` хүснэгтэд аль хэдийн байгаа бараа байх ёстой.
> Боломжит slug-уудыг загварын **«Барааны slug»** хуудас, эсвэл каталогийн
> бараа тус бүрийн URL хаягаас (`/products/<slug>`) авна. Танихгүй slug дээр
> скрипт алдаа зааж зогсоно.

## Багана тус бүрийн тайлбар

| Багана | Заавал? | Утга / формат | Жишээ |
|---|---|---|---|
| `slug (URL)` | ➖ | Багцын URL хаяг. Хоосон бол **нэрнээс автоматаар** үүснэ. | `ovliin-dulaan-4` |
| `Нэр` | ✅ | Багцын нэр | `Өвлийн дулаан 4` |
| `Хүйс` | ➖ | `male` / `female` / `unisex`. Хоосон бол `unisex`. | `male` |
| `Тайлбар` | ➖ | Танилцуулга текст | `Хүйтэнд тохирох дулаан 4 үнэртэн.` |
| `Хямдрал %` | ➖ | Зөвхөн тоо (0–100). Хоосон бол **5**. ₮ биш. | `5` |
| `Бэлгийн ml` | ➖ | Нэмэлт бэлгийн хэмжээ. Хоосон бол глобал тохиргоо (1ml). Зөвшөөрөх: `1`/`2`. | `1` |
| `Зургийн URL` | ➖ | Багцын нүүр зураг (нэг URL) | `https://…/winter.jpg` |
| `Идэвхтэй` | ➖ | `TRUE`=нийтэлнэ / `FALSE`=нуух. Хоосон бол `TRUE`. | `TRUE` |
| `Онцлох` | ➖ | `TRUE`=нүүр хуудсанд онцолно. Хоосон бол `FALSE`. | `TRUE` |
| `Үнэртэн slug 1` | ✅ | 1-р үнэртний бараа slug | `tom-ford-oud-wood` |
| `Үнэртэн slug 2` | ✅ | 2-р үнэртний slug | `creed-aventus` |
| `Үнэртэн slug 3` | ✅ | 3-р үнэртний slug | `dior-sauvage-edp` |
| `Үнэртэн slug 4` | ✅ | 4-р үнэртний slug | `ysl-libre-edp` |

✅ = заавал · ➖ = заавал биш

### Анхаарах
- **Тоон талбарт** (`Хямдрал %`, `Бэлгийн ml`) таслал, ₮, зай бүү тавь.
- Багцын **үнэ энд байхгүй** — систем гишүүдийн үнээс хямдралыг хасаж
  автоматаар бодно (ml сонголтоор live). Зөвхөн хямдралын **хувь**-ийг бичнэ.
- Ижил `slug`-тай багц дахин импортлоход хуучин дээр нь **шинэчилнэ** (upsert),
  давхардуулж үүсгэхгүй. Гишүүд бүрэн дахин бичигдэнэ.

## Импорт (хөгжүүлэгчид)

**Урьдчилсан нөхцөл:** `0028_collections.sql` migration DB дээр ажилласан байх
(`collections`, `collection_items`, `settings.collection`). Env: `NEXT_PUBLIC_SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY` (`.env.local`).

```bash
# 1) Эхлээд зөвхөн шалгах (DB-д хүрэхгүй) — Excel-ийн бүтэц зөв эсэхийг харна
pnpm db:import-collections docs/collection-import-template.xlsx --dry

# 2) Бодитоор DB рүү оруулах
pnpm db:import-collections docs/collection-import-template.xlsx
```

Скрипт ([`scripts/import-collections.ts`](../scripts/import-collections.ts)) нь:
1. «Багц» хуудсыг уншиж, мөр бүрийг шалгана (нэр, яг 4 давхардахгүй slug, хямдрал 0–100).
2. Бүх үнэртний slug-ийг `products`-оос id-руу хөрвүүлнэ (олдоогүй бол алдаа зааж зогсоно).
3. `collections` (type=`base`) мөрийг `slug`-аар **upsert** хийнэ.
4. `collection_items`-ийг дахин бичнэ (4 бараа, `sort_order` 1–4).
5. Хэдэн шинэ / шинэчилсэн болохыг хэвлэнэ.

> Custom (хэрэглэгчийн) багц энэ импортод хамаарахгүй — тэдгээрийг хэрэглэгч
> сайт дээрээс өөрөө угсарна (`collection-requirement.md` §4).

# Сайжруулалтын санаанууд — Техник, library, хэрэглэгч татах арга

Кодын баазыг судалсны үндсэн дээр гаргасан техникийн сайжруулалт, ашиглаж болох library, өсөлтийн аргууд. Одоогийн стек (Next.js 16, Supabase, Tailwind 4, Zustand, React Query) зөв сонгогдсон — эдгээр нь түүн дээр нэмэгдэх зүйлс.

## Аюулгүй байдал, найдвартай ажиллагаа (эхэлж хийвэл зохино)

1. **QPay webhook-ийг баталгаажуулах.** Callback ирмэгц шууд итгэхийн оронд QPay-ийн `/payment/check` API-аар invoice-ийн төлөвийг дахин лавлаж байж «төлсөн» болгох. Кодод өөрт нь энэ тухай NOTE бий (`webhook/route.ts`) — release-ийн өмнө заавал.
2. **API-д rate limit.** `@upstash/ratelimit` (Redis-гүй бол Vercel KV) — нэвтрэлт, купон шалгах, захиалга үүсгэх route-уудад. Утасны нэвтрэлтийн түгжээ бэлэн ч бусад route нээлттэй.
3. **Sentry** (`@sentry/nextjs`) — production дээр алдааг цаг тухайд нь мэдэх цорын ганц найдвартай арга. Демо горим ба бодит горим хоёрын зөрүүг илрүүлэхэд онцгой хэрэгтэй.
4. **`xlsx` санг солих.** Одоо devDependency-д буй `xlsx` (SheetJS) нь npm дээр мэдэгдэж буй эмзэг байдалтай, шинэчлэлт нь зогссон. (2026-08-21: client CSV-г хангалттай гэсэн тул xlsx экспорт хэрэггүй — гэхдээ импортын скриптүүд энэ санг ашигладаг тул аюулгүй байдлын үүднээс **`exceljs`**-ээр солихыг зөвлөсөн хэвээр.)
5. **Резервийн туршилт нэмэх.** Inventory reserve/commit/release, place_order, купон, оноoны SQL логик тесттгүй. Supabase-ийн local DB дээр pgTAP эсвэл vitest + service-role integration тест — мөнгөтэй холбоотой логикийн хувьд хамгийн өгөөжтэй тест.

## Хэрэглэгчийн туршлага (UX)

6. **Зургийн zoom/lightbox** — `yet-another-react-lightbox` (жижиг, Next/Image-тэй зохицдог) — requirement-ийн zoom шаардлагыг шууд хаана.
7. **Carousel-уудыг Embla-руу нэгтгэх.** Одоо галерей, hero, popup тус бүр өөрийн гар бичмэл carousel-тэй. `embla-carousel-react` (8kb) нэг санд нэгтгэвэл touch swipe, autoplay, dots бүгд нэг мөр болно.
8. **Skeleton + optimistic UI.** Сагсанд нэмэх, wishlist дарахад optimistic шинэчлэлт (Zustand-д хялбар); каталогийн шүүлтэд `useOptimistic`/`startTransition` — шүүлт даралт бүрт URL солигддог тул мэдрэгдэхүйц хурдан болно.
9. **Хайлтын transliteration.** «Том форд» гэж кириллээр бичихэд Tom Ford олддог болгох — кирилл→латин хөрвүүлэх жижиг map + `pg_trgm` extension-ээр fuzzy хайлт (Supabase дээр асаахад л болно). Монгол хэрэглэгч брэндийг кириллээр бичих нь элбэг тул бодит ашигтай.
10. **PWA + push notification.** `@serwist/next`-ээр суулгаж болдог апп болгох; push-ээр хямдрал, restock мэдэгдэл — апп хөгжүүлэлгүйгээр апп-ын үр өгөөж.
11. **Checkout-ийг алхамчлах.** Одоогийн нэг урт хуудсыг «Хаяг → Хүргэлт → Төлбөр» гэсэн 2–3 алхам болговол утсан дээр бөглөлт дуусгах хувь өсдөг (гар утасны худалдан авагч давамгай гэж таамаглавал).

## Хэрэглэгч татах, хөрвүүлэлт

12. **Analytics-ийг e-commerce event-тэй болгох.** GA4 `view_item / add_to_cart / begin_checkout / purchase` + Meta Pixel-ийн ижил event-ууд. Одоо зөвхөн pageview байгаа тул **аль сурталчилгаа борлуулалт авчирсныг хэмжих боломжгүй** — Meta ads явуулмагц энэ нь хамгийн эхний хэрэгцээ болно. Meta-ийн Conversions API (сервер талын event)-г давхар нэмбэл iOS-ийн хязгаарлалтыг тойрно.
13. **SEO бүтэцжүүлсэн дата.** `Product` + `AggregateRating` JSON-LD — Google-ийн үр дүнд үнэ, одтой гарна; `next-sitemap`-аар sitemap; барааны OG зургийг `next/og`-оор автоматаар үүсгэх (нэр, брэнд, үнэтэй card) — Messenger-т линк хуваалцахад үзэмжтэй харагдана.
14. **Facebook Messenger чат залгаас.** Requirement-д «пэйж чатаар холбогдох» гэж байгаа — Meta-ийн Customer Chat plugin-ийг сайтад суулгавал хэрэглэгч сайтаас гаралгүй асуулт асууна. Монгол худалдан авагчийн хамгийн дассан суваг.
15. **Popup-д купоны countdown.** Хугацаатай купоны popup дээр «2 өдөр 14:32:11 үлдлээ» гэсэн тоологч — яаралтай мэдрэмж хөрвүүлэлтийг мэдэгдэхүйц өсгөдөг. Popup-ийн startsAt/endsAt бэлэн тул хялбар.
16. **Хүрдийг татах хөшүүрэг болгож хийх.** Хүрд хийгдэхдээ зөвхөн бүртгэлтэй хэрэглэгчид байх тул «эргүүлэхийн тулд бүртгүүл» урсгал нь бүртгэлийн тоог өсгөх гол механик болно. Library: `react-custom-roulette` эсвэл CSS transform-оор өөрсдөө (магадлалыг ЗААВАЛ сервер талд бодох — client-д ирсэн үр дүнг зөвхөн харуулах).
17. **Имэйл автоматжуулалт — Resend + React Email.** Кодод `TODO(resend)` аль хэдийн бий. Захиалгын баталгаажуулалт, орхигдсон сагсны сануулга (24 цагийн дараа), newsletter илгээлт — гурвуулаа нэг сангаар шийдэгдэнэ. Орхигдсон сагсны имэйл нь e-commerce-ийн хамгийн өндөр ROI-той автоматжуулалт гэж тооцогддог.

## Кодын чанар, дэд бүтэц

18. **Component/E2E тест.** `vitest.config.ts` одоо `.tsx` тестийг хамардаггүй — jsdom орчин нэмж Testing Library-ээр гол компонентуудыг (сагс, checkout форм) турших; худалдан авалтын бүрэн урсгалд **Playwright** e2e (checkout → mock QPay → success) — регрессээс хамгаалах хамгийн үнэ цэнтэй нэг тест.
19. **Supabase Realtime-ээр админ мэдэгдэл.** Шинэ захиалга ормогц админ панел нээлттэй байхад toast + дуут мэдэгдэл — Supabase-д багтсан боломж, нэмэлт үйлчилгээ шаардахгүй.
20. **Wishlist-ийг DB-тэй sync хийх.** `wishlists` хүснэгт, RLS бүгд бэлэн — нэвтрэх үед localStorage-оо merge хийгээд цаашид DB-д бичихэд л болно. Cross-device ажиллана.
21. **Зэрэгцээ migration дугаарыг цэгцлэх.** `0028`, `0029` тус бүр давхардсан (`0028_verify_mn` / `0028_collections` г.м.) — дараалал чухал runner-т эрсдэлтэй тул дугаарыг дахин эрэмбэлэх.
22. **Устгагдсан баримтын лавлагааг цэвэрлэх.** Кодын коммент дотор `todo.md B5b`, `requirement_fb.md` зэрэг working tree-гээс устгагдсан файлуудыг заасан лавлагаанууд үлдсэн — шинэ баримтын бүтцэд тааруулж засах.
23. **Bundle шинжилгээ** — `@next/bundle-analyzer`-аар том хуудсуудын жинг хянах; `lucide-react`-ийн импортууд named тул modularize хэрэггүй ч шалгаж баталгаажуулах.

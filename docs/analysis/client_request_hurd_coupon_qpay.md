# Клиентээс тодруулах мэдээлэл — Хүрд, Купон, Tag, QPay

Дараах хэсэг бүрд **бидэнд яг ямар мэдээлэл хэрэгтэй** болохыг жишээтэй нь гаргалаа. Жишээн дээрх утгуудыг өөрийн бодит утгаар сольж бөглөөд өгөхөд л хангалттай. Ингэснээр дахин засварлах, буруу ойлголцох эрсдэлгүйгээр нэг удаад зөв хийх боломжтой.

---

## 1. Хүрд (Азын хүрд)

Одоогоор бидэнд байгаа мэдээлэл: сонголтууд нь супер хонжвор (бүтэн үнэртэй ус), sample, 4 ш «Баярлалаа», 3 төрлийн купон, мөн тус бүр өөрийн магадлалтай.

Хүрдийг хөгжүүлэхийн тулд **хэсэг тус бүрийн нэр, магадлал, олгох арга**-ыг бүрэн жагсааж өгнө үү. Магадлалуудын нийлбэр 100% байх ёстой.

### Жишээ (ингэж бөглөж өгнө үү)

| № | Хүрдний хэсэг | Магадлал | Тайлбар |
|---|---|---|---|
| 1 | Супер хонжвор — бүтэн үнэртэй ус | 1% | Сард дээд тал нь 1 ш |
| 2 | Sample үнэртэй ус | 9% | Дараагийн захиалгад дагалдана |
| 3 | 5% купон | 12% | 14 хоног хүчинтэй |
| 4 | 10% купон | 8% | 14 хоног хүчинтэй |
| 5 | 10,000₮ купон | 5% | 100,000₮-с дээш захиалгад |
| 6 | Баярлалаа | 16.25% | Бэлэггүй |
| 7 | Баярлалаа | 16.25% | Бэлэггүй |
| 8 | Баярлалаа | 16.25% | Бэлэггүй |
| 9 | Баярлалаа | 16.25% | Бэлэггүй |
| | **Нийт** | **100%** | |

### Нэмж тодруулах асуултууд

1. **Магадлалыг админ өөрөө тохируулж болдог байх уу**, эсвэл нэг удаа тогтоод хөдөлгөхгүй юу?
2. **Супер хонжвор болон sample-д тоо ширхгийн хязгаар** байх уу? (Жишээ нь: сард 1 ш, дууссан бол тухайн хэсэг таарахгүй болох гэх мэт.)
3. Биет бэлэг (ус, sample) таарсан хэрэглэгчид **яаж олгох вэ** — дараагийн захиалгад автоматаар дагалдуулах уу, очиж авах уу? Авах хугацаа дуусах уу?
4. Хүрднээс хожсон **купоны хүчинтэй хугацаа** хэд хоног байх вэ?
5. Өдрийн үнэгүй эрх **шөнө 00:00 цагт шинэчлэгдэх үү**, эсвэл сүүлд эргүүлснээс хойш 24 цаг тоолох уу?
6. «100,000₮ тутамд 1 нэмэлт эрх» — **нэг захиалгын дүнгээс үү, нийт хуримтлалаас уу?** Нэмэлт эрх хэзээ дуустал хүчинтэй вэ?

## 2. Купон — төрөл тус бүрийн мэдээлэл

Купон бүрд дараах талбаруудыг тодорхойлж өгнө үү. **Ямар ч төрлийн мэдээлэл орхигдохгүй байх нь чухал** — нэг талбар тодорхойгүй бол тухайн купоныг бүрэн хөгжүүлэх боломжгүй.

### Жишээ (ингэж бөглөж өгнө үү)

| Талбар | Жишээ утга |
|---|---|
| Нэр / код | WELCOME10 |
| Төрөл | Хувиар хямдруулах (өөр сонголт: тогтмол дүн, үнэгүй хүргэлт) |
| Хэмжээ | 10% |
| Доод захиалгын дүн | 50,000₮ |
| Хүчинтэй хугацаа | 2026-09-01 – 2026-09-30 (эсвэл олгосноос хойш 14 хоног) |
| Нэг хэрэглэгч хэдэн удаа | 1 удаа |
| Нийт хэрэглэх дээд тоо | 200 удаа (хязгааргүй ч байж болно) |
| Оноотой давхар хэрэглэж болох уу | Тийм / Үгүй |
| Өөр купонтой давхардах уу | Үгүй |
| Олгох суваг | Хүрд / 300,000₮-ийн автомат купон / Нийтэд зарлах (popup) |

Одоогоор бидний мэдэж байгаа сувгууд: хүрднээс олгох 3 төрөл, 300,000₮-с дээш худалдан авалтын автомат купон, нийтэд зарлах купон. **Өөр төрөл, суваг байвал бүгдийг нь жагсааж өгнө үү.**

## 3. Нэмэлт tag (шошго)

Олон tag байхад асуудалгүй — админ өөрөө чөлөөтэй үүсгэдэг байхаар хийж болно. Гэхдээ дараахыг тодруулж өгнө үү:

1. **Эхлээд ямар tag-ууд хэрэгтэй вэ?** Жишээ нь: «Шинэ», «Хямдралтай», «Бестселлер», «Эрэгтэй», «Эмэгтэй», «Unisex», «Хязгаарлагдмал тоотой», «Улирлын» гэх мэт.
2. Tag **хаана харагдах вэ** — барааны зураг дээр badge хэлбэрээр үү, шүүлтүүр (filter) дээр үү, хоёуланд нь уу?
3. Tag бүр **өөрийн өнгөтэй** байх уу? (Жишээ нь: «Шинэ» — ногоон, «Хямдралтай» — улаан.)
4. Нэг бараанд **хамгийн олон хэдэн tag** зүүж болох вэ?

## 4. Шинэ санаа — Бэлгийн карт (Gift card)

Санал болгож буй хэлбэр: хэрэглэгч 20,000₮ / 50,000₮ / 100,000₮-ийн бэлгийн карт худалдаж аваад (QPay-ээр төлнө), код нь өөрт нь эсвэл бэлэг авах хүний утсанд очно. Хүлээн авсан хүн тухайн кодыг захиалга хийхдээ купон шиг оруулж ашиглана.

Хэрэв энэ санааг хэрэгжүүлэх бол дараахыг шийдэх хэрэгтэй:

1. Ямар **дэвсгэртүүдтэй** байх вэ? (20к / 50к / 100к гэх мэт, эсвэл дурын дүн?)
2. **Хүчинтэй хугацаа** — жишээ нь худалдаж авснаас хойш 6 сар?
3. **Хэсэгчлэн ашиглаж болох уу?** (50,000₮-ийн картаар 30,000₮-ийн захиалга хийвэл үлдэгдэл 20,000₮ хадгалагдах уу, эсвэл нэг удаа л ашиглах уу?)
4. Энэ ажлыг **одоогийн шатанд хийх үү**, дараагийн шатанд төлөвлөх үү?

Мөн бидний зүгээс шинэ санаа гарвал аль болох эрт танд мэдэгдэж байх болно — та ч гэсэн санаа гарвал эрт хэлээрэй гэсэн хүсэлтийг тань хүлээн авлаа.

## 5. QPay холболт

QPay-тэй холбогдохын тулд **та бүхний зүгээс** дараах зүйлс хэрэгтэй. Гэрээний процесс хугацаа шаарддаг тул аль болох эрт эхлүүлэхийг зөвлөж байна.

1. **QPay-тэй мерчант гэрээ** байгуулсан эсэх? Байгуулаагүй бол компанийн улсын бүртгэлийн гэрчилгээ, банкны дансны мэдээллээр QPay-д хүсэлт гаргаж гэрээ хийнэ.
2. Гэрээ хийгдсэний дараа QPay-с олгох **холболтын мэдээлэл** бидэнд хэрэгтэй:
   - Merchant username / password (client_id, client_secret)
   - Invoice code
3. Туршилтын орчинд шалгахын тулд **тест (sandbox) эрх** олгогддог — үүнийг мөн QPay-с хамт авбал сайн.
4. Төлбөр амжилттай болмогц захиалга автоматаар баталгаажих зарчмаар хөгжүүлнэ. **Төлбөр буцаах (refund) тохиолдол** гардаг бол ямар журмаар шийдэхээ тодорхойлж өгнө үү.

---

## Дүгнэлт

Дээрх 5 хэсгийн хүснэгт, асуултуудыг бөглөж өгснөөр бид таамаглалгүйгээр, нэг удаад зөв хөгжүүлэлт хийх боломжтой болно. Аль нэг хэсэг нь тодорхойгүй бол тухайн хэсгээс эхлээд хамтдаа ярилцаж тодруулъя.
